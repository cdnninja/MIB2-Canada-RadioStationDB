MIB2 CANADA RADIOSTATIONDB - INSTALL
====================================

For Harman MIB2 High / MIB2.5 High units (MHI2 / MHI2Q) with M.I.B. (More Incredible Bash)
installed in the green engineering menu (GEM). Use at your own risk.

Keep the car on external power and never pull the SD card or power while files are written.

IMPORTANT - NORTH AMERICAN FIRMWARE
   Steps 1 to 4 alone do NOT make logos show on North American firmware: the unit never starts
   its radio station database service. Step 5 starts it, but ONLY on firmware
   MHI2Q_US_AUG22_P5087 (MU1316). There is no fix for other versions yet.

1. BACK UP
   In GEM > m.i.b., run a backup that includes RSDB (the radio station database).
   Copy the backup folder off the SD card and keep it somewhere safe.

2. COPY
   Copy the "mod" folder from this zip to the ROOT of your M.I.B. SD card, so the file is at
       /mod/RSDB/VW_STL_DB.sqlite
   Do not rename the file. Put the card in slot SD1.

3. INSTALL
   GEM > m.i.b. > multimedia_system > radio > radiostation_db > "Copy RSDB to unit"
   Wait until it says it is done, then reboot the unit.

4. TURN THE FEATURE ON (North American units)
   On the same M.I.B. screen set "RSDB region" = EU, press save, reboot.
   (North American units ship with "none", which switches the logo database off.)

5. START THE RADIO STATION DATABASE SERVICE - ONLY FOR MHI2Q_US_AUG22_P5087 (MU1316)
   ONLY do this step on firmware MHI2Q_US_AUG22_P5087, MU1316. Do NOT use it on any other version.
   Check your version in the M.I.B. backup from step 1: the file <MU>-allversions.txt must say
       Train = MHI2Q_US_AUG22_P5087
       MU = MU1316
   North American firmware never starts the unit's radio station database service, so no logos
   show even with the database installed. On MU1316 a replacement HMI startup file fixes this:
   it is that firmware's own startup file with one entry added ("RadioStationDB"). Other firmware
   versions have a different startup file, so this one must not be placed on them.
   RISK: this puts a file on the unit's app partition that changes what the HMI starts at boot.
   It has been used on one car. Keep the car on external power.

   The files for this step are in this zip, in the folder "hmi_startup_fix_MU1316_only"
   (its README.md explains what the fix changes). They are kept apart from "mod" on purpose.

   a. Copy the contents of hmi_startup_fix_MU1316_only/sdcard to the ROOT of the M.I.B. SD card:
          /mod/RSDB/hmi_startup.json
          /esd/scripts/rsdb_hmi_install.sh
          /esd/scripts/rsdb_hmi_remove.sh
   b. Add the two buttons: open /esd/Launcher-sda0.esd on the SD card in a text editor, find
          label   "Copy RSDB to unit"
      and paste the contents of hmi_startup_fix_MU1316_only/Launcher-sda0.esd.snippet on the
      next line. Save the file.
   c. GEM > m.i.b. > multimedia_system > radio > radiostation_db >
          "Canada RSDB: place HMI startup file (MU1316 only)"
      It should say "Unit: MU1316" and "HMI startup file placed".
      If it says ABORTED, nothing was changed:
        - "only for MU1316": your unit is a different version - stop here.
        - "already has /eso/hmi/lsd/hmi_startup.json": the unit already has a startup file; a copy
          was saved to /backup/hmi_startup.json.from_unit on the SD card. Do not continue.
   d. Reboot the unit.

   To remove it: GEM > m.i.b. > multimedia_system > radio > radiostation_db >
       "Canada RSDB: remove HMI startup file", then reboot.
   (A copy is saved to /backup/hmi_startup.json.removed. A firmware update also removes it.)

6. TUNE A STATION
   Leave the station logo region on Automatic (or pick "Canada" if the list is shown).
   Tune an FM station and give RDS a few seconds. Re-save presets if old ones show no logo.

UNDO
   Put your backed-up VW_STL_DB.sqlite in /mod/RSDB/ and run "Copy RSDB to unit" again.
   If you did step 5, also run "Canada RSDB: remove HMI startup file" and reboot.

Report what works (or doesn't) at:
   https://github.com/cdnninja/MIB2-Canada-RadioStationDB/issues
Include your car, unit (e.g. MHI2Q_US_AUG22_P5087), city and the stations you tried.
